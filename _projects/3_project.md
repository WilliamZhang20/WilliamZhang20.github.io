I am developing an algorithmic stock and options [trader](https://github.com/WilliamZhang20/cvx-trader) using the [CVXPY](https://www.cvxpy.org/) Python library.

The work focuses on optimization-driven portfolio and strategy decisions, with an emphasis on making the trading logic explicit and testable.

The algorithms that I test run on an Alpaca paper trading account.
